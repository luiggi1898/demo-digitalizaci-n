# Proyecto Amazon · Luiggi

Web del Proyecto de Digitalización (1ª evaluación) sobre Amazon. Hecha con HTML, Bootstrap 5.3.9 y un poco de JavaScript, siguiendo la estructura de la demo de clase.

## Páginas

- `index.html`: identidad e historia, organización y presencia geográfica (mercado español).
- `evolucion.html`: tabla de 6 hitos y proceso antes/después.
- `futuro.html`: diagnóstico, propuesta de mejora digital y fuentes.
- `contacto.html`: formulario con envío simulado (`js/script.js`).
